# Portfolio: Suphawit Thammarat

One-page portfolio. Next.js 16, TypeScript and Tailwind CSS 4. Static, with no analytics and no cookies.

- Content lives in `lib/content.ts`. Every number there comes from the linked project's own repo or README.
- Project screenshots in `public/work/` are captured from the live sites.
- CV PDFs in `public/cv/` are built from `D:\CV\suphawit\build.py`.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
